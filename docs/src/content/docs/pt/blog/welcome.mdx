Bem-vindo ao blog da **documentação**! Esta publicação foi criada pelo
gerador `ts#astro-docs`.

O blog é alimentado pelo plugin [`starlight-blog`](https://starlight-blog-docs.vercel.app/).
Adicione novas entradas como arquivos MDX em `src/content/docs/<locale>/blog/` com
frontmatter `title`, `date` e `authors`.
